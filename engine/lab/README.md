# engine/lab/ — 新实验脚本目录（2026-10-02 起的约定）

> 背景：`engine/` 曾平铺 64 个 .py，生产面与实验面不可分（详见
> `docs/架构评审-2026-10-02.md` P1-2）。自 2026-10-02 起，**新的实验/诊断脚本统一放本目录**。

## 约定

1. **存量不迁**：`engine/` 根下 30+8 个历史 lab_*/diag* 脚本原地保留，保证 2026-10-02 之前的
   文档复现命令逐字可跑。中期若要做一次性迁移，须同步在 docs 加「旧路径为 engine/xxx.py」声明。
2. 实验脚本必须**离线、只读**：不写生产产物、不改 `config.py`（生产口径变更走正式的
   engine_version 升版流程 + 登记簿）。
3. 命名：**日期后缀**（`lab_<主题>_20261002.py`），不用数字版本后缀（diag2/diag3 式命名无法自解释）。
4. 生命周期：结论写入 `docs/` 实验文档 + 登记 `web/public/data/experiments.json` 后，
   一次性诊断脚本可删（登记簿记录其去向）；实验台脚本保留供复现。
5. 自证要求：凡涉及重放/结算的实验台，须内置 `verify` 类模式自证与生产逐位一致
   （参照 `engine/lab_flex.py` 的做法），否则结论不可信。
