## 一、给交叉验证方的一段话（可直接转发）

> 这是一套「行业方向判断 + ETF 收益结算」的双层系统。请按下面的规格独立复现，
> 重点是**判定边界**，不是收益数字本身。规格文件里的每个常量都标注了生产源码位置。
> 若你的结果与本文「验收锚点」不一致，优先检查第四节列的 8 个口径陷阱——
> 历史上每一处都真实造成过偏差。

## 二、规则速查

### 买入（信号层，决定出什么结论）

| 步骤 | 规则 | 关键参数 |
|---|---|---|
| 1. 候选池 | 申万一级 31 个 + 细分赛道，`ret_60` 非空 | — |
| 2. 六维打分 | mainline / pullback / exhaust / rebound / risk / regime_fit，各 0–100 | `BASE_WEIGHTS` 见 config |
| 3. 综合分 | `Σ(base_k·adj_k·dim_k) / Σ(base_k·adj_k)`，按当日 regime 调权 | `REGIME_WEIGHT_ADJ` |
| 4. 硬回避 | `mainline<30` 或 `dist_ma250>0.45` 或 `risk<22` **且** `composite>=50` → AVOID | — |
| 5. 入手 | `composite>=64` 且 `mainline>=58` 且 `rebound>=55` 且 `risk>=35` | `max_buy_now=4` |
| 6. 埋伏 | `composite>=56` 且 `mainline>=52` 且 `pullback>=52` 且 `exhaust>=50` | 补足到 8 |
| 7. Top 选取 | 先取入手前 4，再取埋伏前 `8−入手数`；**入手全部排在埋伏前** | `max_daily_picks=8` |
| 8. 前置过滤 | `rs_120<0` 或 `pos60>0.95` → 降级 AVOID；**被降级的不补位** | `CONCLUSION_FILTER` |

### 建仓（结算层，决定资金怎么进）

| 项 | 规则 |
|---|---|
| 时点 | 信号日 T 收盘出结论 → **T+1 开盘买入** |
| 容量 | `max_holdings = 8 × 4 = 32`；每日新开仓上限 `max_new_per_day = 2`，按综合分降序取 |
| 排序 | 计划内按 `composite` 降序；`room = 32 − 当日到期剔除后的持仓数` |
| 权重 | `w = 1/max(σ₆₀, 0.05)`（风险平价）再乘 `(综合分/50)^0.5` |
| 总暴露 | `expo = clip(0.16 / σ_组合, 0.80, 1.0)`，需 ≥20 个历史日；未投入部分按 1.5%/年计现金 |
| 成本 | 双边 0.0014（万二佣金 + 万五滑点，ETF 免印花税） |

### 卖出（结算层，两套口径）

| 口径 | 规则 | 用途 |
|---|---|---|
| **主口径** | `T+1+H` 收盘卖出（H = 建议周期 60/80/100）；卖出日无行情则向前找最近有成交日 | 生产资金曲线 |
| 对照口径 B | 区间内**连续 3 日**收盘跌破该 ETF 自身 MA20 → **次日开盘**平仓 | 复盘页对照（不进生产） |
| 失效预警 | 「今日出手」按口径 B 判定，回溯最多 9 日，达 3 日即提示 | 风险提示，不触发卖出 |

### 建议周期怎么来（horizon.py）

状态向量 6 维（五维分 + 环境分）；在该标的自身历史里找最近的 40 个「未来窗口完整」的日子；
对 H ∈ {60, 80, 100} 算 `risk_adj = 平均超额 − 0.25×|平均最大回撤|`，取最大者；
样本 < 12 个则**回退 H = 20**。

## 三、评估口径（交叉验证的「标准答案」怎么数）

- **信号口径**：行业指数收益 − 申万一级等权指数（EW）收益 = `ex_ew`
- **结算口径**：ETF 净收益（含成本）− 基准 ETF（510300）净收益 = `ex_bench`
- 两者都用同一阈值：`≥ +2%` 记对，`≤ −3%` 记错，中间记中性
- 可结算 = ETF 已上市且买卖两端都有行情；否则只进信号口径，不进任何曲线

## 四、8 个口径陷阱（历史真实踩过，优先核对）

1. **权重公式**：正确 `(score/50)**tilt`；错误 `score**tilt/50`。后者等于给高分加隐性杠杆，虚高约 1pp。
2. **建仓当日就要乘 tilt**：留到次日循环才乘，只在 `tilt>0` 的用例上产生 0.04pp 偏差。
3. **`room` 用「到期剔除后」的持仓数**：先结算到期、再算剩余容量，顺序不能反。
4. **Top 选取在过滤之前**：先切 4+4，再剔除 `rs120<0 / pos60>0.95`，且**不补位**（当日结论数可以 < 8）。
5. **硬回避的控制流**：必须 `is_avoid` **且** `composite>=50` 才提前返回 AVOID；只满足前者会继续走判定（结果仍是 WATCH，但分支不同）。
6. **`due_in` 是纯计数**：`end − as_of` 不依赖未来价格，即使到期日超出数据末端也照算；只有日历日才置空。
7. **重建持仓时到期日不截断**：截断会把「周期未走完」误判成「今日到期」。
8. **`rs_k` 是相对行业等权 EW**，不是相对沪深300；`pos60` 用 60 日 hi/lo 直接算，差一个 shift 就会改变过滤集合。

## 五、验收锚点（全量区间 2016-01-04 → 2026-09-21，2606 个净值点）

| 层面 | 指标 | 期望值 |
|---|---|---|
| 信号 | 已评估 / 对 / 错 / 中性 | 1449 / 607 / 588 / 254 |
| 信号 | 方向胜率（RIGHT 占比） | **41.89%** |
| 信号 | 平均超额 | +2.19% |
| 结算 | 可结算 / 仅信号 / 合计 | 1032 / 417 / 1449 |
| 结算 | 胜率（跑赢基准） | **39.34%** |
| 结算 | 胜率（绝对正收益） | 49.61% |
| 组合 | 年化 / 最大回撤 | **12.57% / −29.91%**（回撤日 2022-04-26） |
| 组合 | 总收益 / 波动 / Sharpe | +240.22% / 19.49% / 0.705 |
| 组合 | 基准（510300）年化 / 回撤 | 4.16% / −44.75% |
| 执行 | 计划 / 成交 / 容量挡下 | 1032 / 328 / 347 |
| 执行 | 平均持仓数 / 平均暴露 / 平均投入 | 10.19 / 0.902 / 0.262 |
| 执行 | 买入笔数 / 卖出笔数 / 不同 ETF 数 | 328 / 328 / 25 |
| 持仓 | 组合口径 / 信号口径 / 口径 B | 80.9 日 / 78.8 日 / 10.2 日 |
| 过滤 | 被降级结论数 | 328 |

**关于 `1032 − 328 = 704` 而 `blocked_by_capacity = 347`**：这不是错。
`max_new_per_day=2` 的截断发生在容量计数**之前**，被它削掉的部分不计数；
`adds[:room]` 中仍可能因缺开盘价被跳过（也不计数）。
所以 `blocked_by_capacity` 是下界近似，**不要用它做等式配平**。

## 六、已知边界（不是 bug，是显式口径）

- `min_days = 20` 的 3 笔持仓，来自「样本不足回退默认周期 20」。
- 计划里 `卖出日 ≥ 数据末端` 的结论被静默丢弃（周期未走完），不计入任何计数。
- `n_settled(1032)` 与 `planned_trades(1032)` 数值相同属巧合，定义不同。
- 口径 B 的 `cagr 6.70% / maxdd −40.17%` 明显劣于主口径 —— 这正是它不进生产的原因。
- 同 ETF 槽位上限（`max_per_sid`）已实现但未启用：实验证明它不构成 Pareto 改进
  （回撤 −3.5pp 换年化 −2.6pp），仅在复盘页作为取舍对照展示。
