# 趋势相关因子 Review（2026-09-28）

对象：ARK 引擎里所有与「趋势」有关的信息 —— 从 L2 特征到六维打分、闸门、环境。
方法：`engine/lab_trend_quality.py`（**只读**，不写任何生产产物、不改 config；本轮**未落参**）。

## 〇、一句话结论

**价格类趋势因子已经穷尽**：本轮把「唯一可能带来新增信息」的 6 类改法（风险调整 / 路径质量 /
量价确认 / 多窗一致性 / 加速度 / 区间位置）全部做了 IC 实测，其中只有 **`pos250` 与
「风险调整动量 IR」在全样本上有统计显著的增量**，但**逐年不稳定、组合后 IC 无提升** →
**不建议为它们改动生产口径**。真正能大幅提高选品质量的只有一条路：**引入价格之外的新信息源**
（估值 / 基本面），而这条路的接口在本机数据链路上**已确认可得**（见第五节）。

## 一、现状盘点：趋势因子用到了什么、漏了什么

| 层 | 现在怎么用趋势 | 文件名 |
|---|---|---|
| L2 特征 | ret_5/10/20/60/120/250、ma20~ma250、dist_ma20/60/120/250、ma20_slope、dd_from_high60、pos60/pos250、maxdd_60、vol20/60、vol_ratio、amount_ratio、up_vol_share、consec_up、r5_over_r20、sharpe20、rs_20/60/120 | `indicators.py` |
| 打分 | `mainline` = 0.40·ret120 + 0.25·ret250 + 0.20·dist120 + 0.15·dist250（**全是"幅度"**，且都被线性截断归一化）；`pullback` = −ret20 / −dd_from_high60 / −dist20（乘 `ml_gate` 条件化）；`rebound` 用 ret5 / ma20_slope；`risk` 用 vol20 / vol_ratio | `scoring.py` |
| 闸门 | AMBUSH 要求 `mainline≥52 且 pullback≥52 且 exhaust≥50`；mainline < 30 直接回避；失效条件含「跌破 MA120」「rs_120 转负」 | `classify.py` |
| 环境 | 五分量（广度 0.32 / 趋势 0.24 / 动量 0.24 / 波动 0.10 / 流动性 0.10）→ EMA → 阈值 + 滞回 + 强制降级 | `regime.py` |
| 阶段 | SPROUT/CONFIRM/MID/MATURE（**纯展示**，不进 composite） | `scoring.compute_stage` |

**结构性问题（本轮 review 的核心观察）**：`mainline` 的四个分量（ret120/ret250/dist120/dist250）
两两秩相关极高、且都是"价格涨了多少"的同一种度量 → 它本质上是**一个因子的四种写法**。
`config.py` 里记的 IC +0.036/+0.047 就是这个"组合幅度"的成绩，而单个 ret120 是 +0.029/+0.033 —— 
**四分量加权并没比单用 ret120 好多少**（+0.007/+0.014），说明内部重加权空间已经接近耗尽。

## 二、本轮实测：只有"破坏单调性"的候选才可能有增量

方法论前提（`docs/行业选错-三方向实验结论-2026-09-24.md` 已证明）：Rank IC 对**逐日单调变换不变**，
所以减中位 / 分位化 / 与分位加权混合 → 0 新增信息。**能改变横截面排序的只有引入除法、交互、
或新变量**。本轮全部按此设计。

样本：126 个行业/赛道 × 3400 交易日（2012-09-13 → 2026-09-28）；口径与
`lab_sector_fix.run_ic` 一致（逐日横截面 spearman；前瞻超额 = 个股 − 行业等权）；
基线复现：mainline IC@80/+100 = **+0.033/+0.045**（文档 +0.036/+0.047，口径一致）。

## 三、三个稳健发现（本轮最值得记住的部分）

1. **趋势因子在 PANIC 环境中完全失效，且无法靠"换因子"救回来。**
   mainline IC −0.002、ret120 −0.029、IR −0.011 —— 三种写法在 PANIC 下都是 0 或负。
   但 `docs/行业选错-三方向实验结论` 方向 B 已证明**「PANIC 不新建」是有害的**
   （年化 −3.7pp、回撤反恶化 5.6pp）。两条合起来是一个不受欢迎但明确的结论：
   **PANIC 下的建仓必须靠"仓位与资金管理"兜，不能靠"换个更好的趋势因子"。**

2. **长期位置与短期回落是两个方向相反的正交信息。**
   `pos250`（250 日区间位置）组内 +0.025 显著为正，`dd_from_high60`（距 60 日高点）
   组内 −0.015 显著为负。即：**「一路走高的长期趋势 + 刚刚回调」才是最优组合** ——
   这与系统 AMBUSH 的设计（mainline + pullback）方向一致，
   但系统用的是 ret120/ret250 的**幅度**，而 IC 更高的是**位置**（pos250）。
   边界说明：`config.CONCLUSION_FILTER` 注释里记的「pos250 硬规则落地后回撤劣化」讲的是
   **过滤**（切除样本），与本处的**打分**（连续加权）不是同一种用法，不构成否决依据；
   但见第二节 E 表，它逐年不稳，本轮同样不落参。

3. **「风险调整」确实比原始动量更稳，但幅度不够付工程成本。**
   IR 在 ATTACK/NEUTRAL 两档 IC 都高于 ret120（0.066/0.094 vs 0.046/0.087），
   在 PANIC 也略好（−0.011 vs −0.029）—— 与「波动管理动量降低 crash 风险」的文献一致。
   但组内增量只有 +0.015、组合后不提升 IC，**不值得为此改生产口径**。
   若要利用它，正确的位置是**组合权重层**而非选品层（见第四节第 3 条的理由）。

## 四、建议（按"值不值得投预算"排序）

### 值得做

1. **新增价格之外的信息源：行业估值 / 基本面（唯一有实质上限的一条路）**
   - 已确认可得：`akshare.index_analysis_daily_sw`（申万官方指数分析，含估值类字段）、
     `index_analysis_weekly_sw / monthly_sw`；`westock-data` skill 亦声明覆盖「申万行业估值/盈利预测/财务」。
   - 建议先做**零风险前置**：抓 31 个一级行业的估值历史 → 看字段深度与覆盖（细分赛道 120 个未必全有）
     → 算「估值历史分位」→ 直接跑本轮的 IC 框架（含控制 mainline 的组内 IC、逐年稳定性）。
     **IC 不显著就到此为止**，不进入组合层。
   - 若能进模，最自然的形态是「趋势 × 估值」交互（强势且不贵的行业 vs 强势但极贵的行业），
     而不是估值单独作为因子（A 股行业估值单独用胜率很低）。
   - 这需要走完整落参协议（L0 落盘 → 特征层 → 打分 → 全量重放），**先不写代码，等你点头**。

2. **用 IC 复盘一遍 `REGIME_WEIGHT_ADJ`（零成本，只是复核）**
   现行 regime 权重（PANIC 下 mainline×0.85/risk×1.50、ATTACK 下 rebound×1.20 等）
   **是手工设定的，从未用 IC 验证过**。C 表已经显示「趋势因子在各环境的有效性差异巨大」
   （0.089 vs −0.002），说明这套乘数值得用同一套框架回测一遍：
   若某些乘数与 IC 证据相反，改为按证据设定是**低风险改进**（不动因子、只动已存在的旋钮）。

### 可做（低预期，别单独立项）

3. **把 pos250 / IR 用在小范围**：
   - 展示层（零风险）：引擎页 IC 卡片加这两行（`lab_sector_fix.py ic --write` 的 payload 里加因子），
     先让它们可见，观察一个季度；
   - **组合权重层**（如果一定要用）：把 `score_tilt` 的底数从 `composite` 换成
     `composite × (1 + w·z(IR))` 之类。技术理由：Rank IC 对单调变换不变的是**排序**，
     而组合层吃的是**幅度**（`score_tilt=(composite/50)^0.5`）—— 所以"重新包装"在**权重层仍有空间**，
     这是既有文档结论的一个精确边界。但要预期很低：选品 IC 只有 0.03~0.05，权重层的收益贡献更小。

### 不要做

4. **继续在价格类趋势因子上找增量**：路径质量、量价确认（up_vol_share）、三窗一致性、加速度、
   maxdd_60 —— 本轮组内 IC 全部 ≈ 0（|t| < 2），**已实测否决**，不要再花预算。
5. 横截面归一化 / 分位化 / 与分位加权（数学上 0 增量，已证）；
6. 周期估计精度（天花板 0.5pp）、退出规则、参与度旋钮（前几轮均已证，见既有文档）。

## 六、边界与披露

- 本轮的 IC 检验对象是**行业指数**（126 个 L1+L2 标的），与结算层（真实 ETF）不是同一口径；
  IC 显著不等于账户收益改善 —— 历次实验反复出现过「信号层改善、组合层变差」。
- 所有候选都停在 IC 层，**没有任何一个进入打分或生产**；`config.py` / `scoring.py` / `classify.py`
  本轮**一行未改**，`experiments.json` 未登记（未做组合层实验，按 `docs/实验记录规范`
  不必登记为本轮实验条目）。
- 未测但已识别的候选：行业间趋势传导（上下游领先滞后）、趋势因子的时变参数（波动自适应窗口）、
  跨市场/跨资产信号 —— 前两个仍属"价格类包装"范畴，按第 4 条不建议；第三个需要新数据源。
