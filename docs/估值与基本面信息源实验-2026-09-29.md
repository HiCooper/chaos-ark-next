## 〇、一句话结论

**「行业估值」这条最直觉的路被实测否掉了，但同一份数据里挖出了三条真实增量 —— 且都不是「估值便宜」。**

1. **估值分位（PE/PB 历史分位）是趋势因子的非线性反装**：与 `mainline` 的横截面秩相关达
   **−0.423 / −0.708**；它那些看起来「高度显著」的全样本 IC（−0.065，t=−17.0）**全部来自子样本比较假象**——
   分位需要 750 日预热，IC 只在 2015 年后的交易日上算，而那批日子里 mainline 的 IC 是 **0.068**
   （全样本只有 0.041）。同口径一比，Δ 立刻变成 **−0.133 / −0.105**。
2. **「基本面好」在 A 股行业层面是反向的**：隐含 ROE 水平组内 IC **−0.040**(t=−9.6)、
   隐含盈利增速(250d) **−0.033**(t=−11.0)、隐含净资产增速 **−0.016**。
   真正有效的是**变化**而非**水平**：隐含 ROE 的 60 日变化 **+0.018**(t=6.3)。
3. **唯一同时改善 IC 与经济量级的是「拥挤度」**（换手/成交额占比），不是估值：
   `低换手分位` 组内 IC **+0.031**(t=8.6)、与 mainline 秩相关仅 −0.313；
   加进动量分后 IC **0.041 → 0.057**（同口径 Δ=+0.016，全轮最大），
   H=20 的分组收益差 **0.41% → 0.51%**（年化 5.06% → **6.42%**，t 4.7 → **7.0**）。
   **但 H=100 的高分组收益不升反降（1.75% → 1.35%）**，改善主要来自「更会躲差票」。

**按项目四条准则核，两个候选（`BP`、`低换手分位`）都还不够格落参**（详见第四节），
但「拥挤度」是**一条新的、值得再投一轮的方向**；而「行业估值水平/分位」可以**从待验证清单里划掉**。

## 一、数据源：一条真正「价格之外」的通道已打通

申万宏源官方「指数分析」接口（`institute-sw/api/index_analysis/index_analysis_report/`，
即 akshare `index_analysis_daily_sw` 的底层）。**没有直接用 akshare，原因见第六节。**

| 字段 | 含义 | 是否价格之外 |
|---|---|---|
| `pe` / `pb` / `dp` | 市盈率 / 市净率 / 股息率 | ✅ 定价信息 |
| `turnoverrate` | 换手率 | ✅ 量的信息 |
| `bargainsumrate` | 成交额占比 | ✅ |
| `negotiablessharesum1/2` | 流通市值 / 平均流通市值 | ✅ 规模 |
| `closeindex` | 收盘指数 | ❌（仅用于校口径） |

**抓取结果**（`data/raw/sw_valuation/`，L0 write-once）：

- **162 个指数**（一级 31 + 二级 131），**394,191 行**，覆盖 **2012-01-04 → 2026-09-24**，2013 次请求，**零失败**
- 探针实测：历史深度到 **2004-01-14**；`page_size` 服务端上限 **≈200**（1000/5000/20000 一律读超时）
- 可得性：2012–2021 年行业-日覆盖率 **~60%**、2022 年后 **~95-96%**
  （60% 是因为我们的标的池含部分 L3 原名映射进来的行业，而该接口只覆盖一级/二级）；
  120 个行业里 **116 个有数据**，缺 `850813/850814/850817/850818`

**防前视校验（决定性，且不额外发请求）**：分析表 `close` 与价格面板**同日**收盘逐值比对，
**287,730 个行业-日里 286,820 个完全相同（99.68%）**，不等的只是 2017-07-21、2015-12-30
等个别日的末位小差 → **两表日期严格对齐，估值无前视** ✓。
辅证：`Δlog(PB)` 与当日收益相关 **+0.913**（= 逐日盯市重算，不是低频重述值）。

### 隐含基本面：这条接口不直接给盈利，但可以反解

接口只给 PE/PB，没有盈利增速。但 **`PE = P/E`、`PB = P/B`** ⇒ 可分离出：

```
E = P / PE          B = P / PB          ROE = E / B = PB / PE
隐含盈利增速  g_E = Δlog(E) = Δlog(P) − Δlog(PE)
```

关键在于 **E 与 B 不是价格路径的函数**——它们只随财报 / TTM 滚动变化，
所以 `g_E`、`ROE` 是真正的**基本面**信息，而不是价格的换装。这是本轮能拿到的最接近
「盈利 / 盈利增速」的东西。

## 二、方法：为什么必须先做「同口径」对照（本轮最重要的方法论）

分位类因子需要 750/1250 个交易日预热，**只在 2015 年之后才有值**；而 `mainline` 覆盖全样本。
把两者的全样本 IC 并排放，就是在**不同子样本**上比 —— 而这批子样本里的 mainline IC 高得多：

| | IC@100 | 共同日数 |
|---|---|---|
| mainline（全样本） | 0.041 | 3035 |
| mainline（**分位因子有值的那批日子**） | **0.068** | 2543 |

于是任何「与 mainline 负相关」的因子，都会在这批日子里显得「显著为负」——
**凭空造出不存在的信息**。本轮所有 IC 表都配了同口径列（A2 / F 的「ml同日子集」），
正是这一步把「PE 分位 IC=−0.065」这个看起来最漂亮的结论推翻了。

样本口径：120 个行业 × 3400 交易日（2012-09-13 → 2026-09-28）；前瞻超额 = 行业 − 行业等权
（与 `review.fwd_stats` 同构）；`mainline` IC@100 = **+0.041**，与既有文档 +0.045 一致（基线复现 ✓）。

| **0.7·ml + 0.3·低换手分位** | **20** | 0.35% | −0.16% | **0.51%** | **6.42%** | **7.0** | **56.3%** |
| **0.7·ml + 0.3·低换手分位** | 100 | 1.35% | −0.81% | 2.16% | 5.36% | **14.1** | **64.0%** |
| 0.7·ml + 0.3·小市值 | 100 | 1.29% | −0.32% | 1.61% | 3.97% | 10.4 | 59.6% |

「低换手」加入后的机制很清楚：**短期（H=20）确实更好**（差 +24%、年化 +1.36pp、t 4.7→7.0）；
但 H=100 时**高分组收益反而从 1.75% 降到 1.35%**，多出来的是「低分组被压得更低」
（−0.40% → −0.81%）——即它**提升的是「躲差票」的能力，不是「挑好票」的能力**。
对一个**只做多**的策略来说，这是个必须正视的保留意见。

## 四、判定：按项目四条准则逐条核

| 准则 | BP = 1/PB | 低换手分位 | 估值分位类 |
|---|---|---|---|
| ① 先精确复现基线 | ✓（mainline IC@100 0.041 ≈ 文档 0.045） | ✓ | ✓ |
| ② 方向跨参数档一致 | ✗ **只测了「水平」一档，没有参数档** | ✗ **窗口只测 250 日一档** | 方向一致（稳定反向） |
| ③ 参数响应单调 | 未测 | 未测 | 未测 |
| ④ 单年耀眼 | ✗ 逐年 7/4 且含 −0.398、+0.313 的极端摆动 | △ 8/3 且近三年连续为正，较可接受 | 2/9，稳定反向 |
| 组合层能否兑现 | ✗ 分组差为负（−0.75%） | △ H=20 兑现、H=100 只改善回避 | ✗ −2.10% |

**结论：两个候选都还没到可落参的门槛。** 但两者性质不同：

- **`BP`（估值水平）**：组内 IC 是唯一「三档全正」的，说明它确有独立于趋势的信息；
  但**它在分组收益上是负的、逐年极不稳** → 更像「秩相关层面的信号，没有可交易形态」，
  **不建议落参**。
- **`低换手分位`（拥挤度）**：唯一同时改善 IC（Δ+0.016）与短期收益差（年化 +1.36pp）的，
  逐年相对最稳，且与 mainline 重叠只有 −0.313 → **是值得再投一轮的方向**，但必须先补
  参数档扫描 + 组合层真实回测。
- **估值分位（PE/PB 历史分位）**：秩相关 −0.71 已接近「趋势的反面表达」，
  同口径 Δ 为 −0.105/−0.133，分组差 −2.10% →**可以划掉，不要再花预算**。

## 五、下一步建议（仍未落参）

1. **对「拥挤度」做完整的参数档扫描**：换手窗口 60 / 120 / 250 / 500 日 × 权重 0.1~0.4，
   验准则②③（方向一致 + 单调）。这是唯一有希望的线。
2. **把同族的三个量合成一个「拥挤度因子」**：换手分位、换手 60d 变化（−0.038）、
   成交额占比（−0.033）方向完全一致，互证它们不是单指标噪声；合成后再走一遍 IC + 组合层。
3. **组合层验证必须做**：本轮只到 IC / 分组差层面。按 2024 那轮的教训
   （G2 把出手率 4%→23% 却是最差变体），**IC 增量不等于 cagr 增量**。

4. **估值这条线**：已有足够证据否决「行业估值水平/分位」作为独立因子。
   「低估值 × 强趋势」这类交叉项按 D 表（秩相关 −0.71）本质上是趋势的重述，
   不建议再投入。

## 六、附：本机环境与工程坑（复现时必读）

### 数据源与 akshare 的冲突
**不要直接用 `ak.index_analysis_daily_sw`**：它把 `page_size` 硬编码为 50、`swindexcode` 硬编码为 `all`。
全量 39 万行按 50/页要 1.2 万次请求，不可行。`engine/fetch_sw_valuation.py` 直接调 HTTP，
把 page_size 提到 200（实测上限），降到 2013 次请求。

### 一个真实的正确性漏洞
抓取循环把「返回 0 行」当作「这一段翻完了」。若网络抖动被重试逻辑吞成 0 行，
**该段后续所有页会被静默丢弃且看不出来**。已改为抓取路径 `strict=True`（重试耗尽即抛异常），
并把失败页记入 `cache/sw_valuation_fetch.json` 的 `failures` 字段。

### 本机 fork 失败
过程中机器内存被打满（`vm_stat` 空闲页 ~2986 ≈ 12MB），**bash 连 `> file` 重定向都打不开**，
报 `resource temporarily unavailable`；沙箱内外一样、后台通道一样，`echo` 要跑 5 分钟。
这是机器状态、与代码无关。**处置**：给长任务加**分段增量落盘**（本抓取器每 6 段 flush 一次），
并在开工前用 `--bench N` 测一次真实吞吐（实测 2.24 s/请求，全量约 1 小时）。

### 矩阵行序对齐
`ctx["dims"]` 里的矩阵是 `len(fs.codes) × len(dates)`、**按 `fs.codes` 的行序**排的。
一旦把标的池过滤成 L1/L2 子集，必须同步 `row_idx = [fs.codes.index(c) for c in codes]` 再切片，
否则矩阵**静默错位**、IC 全是假的。上一轮 `lab_trend_quality.py` 没做过滤恰好绕过了这个坑。

### 尾部窗口分位
`trailing_pct()` 用 `np.lib.stride_tricks.sliding_window_view` 实现「当日值在自身前 W 日中的分位」，
只用历史窗口 ⇒ 无前视。注意 `scoring.py` 里已有同概念的 `_roll_pct`，两处口径可考虑统一。
