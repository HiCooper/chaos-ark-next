# 随机入场一年（中位 +4.45%）· 第二轮：**只用自己标的**的五条旋钮（2026-09-24）

上一轮（`docs/随机入场一年-归因与突破方向-2026-09-24.md`）的两个方向被否掉的理由是同一个：
**混入了策略信号集之外的标的** —— 方向 B 买了 WATCH 近失候选（不是共振结论），
方向 C 把闲置现金停泊到沪深300ETF（基准本身）。本轮把约束收紧到：

> **候选集 = `load_trades()` 那 2125 条共振结论；标的池 = 它们映射到的行业 ETF。一行不加。**

在这个约束下只剩四个自由度：**持有多久 / 一天能建几笔 / 到期怎么处理 / 闲置现金的收益率**。
五条旋钮全部实测，结论如下。

实验台：`engine/lab_fresh_median.py`（新增 `hold` / `flow` / `cash` / `roll` / `ext` 五个模式，
**只读、不写任何生产产物、不改 config**）。

## 一、先修上一轮的一个口径：中位缺口只有约 1pp 是"β"

上一轮说"中位 = β 暴露不足的度量"，依据是 `corr(平均投出, 一年收益) = +0.56`。
这个相关系数**被行情制度混淆**了（投出高的年份恰好是牛市）。把缺口拆开算：

| 拆解项 | 均值 | 中位 |
|---|---|---|
| 超额（一年收益 − 同期基准） | **+11.25pp** | **+8.37pp**（胜率 65.4%） |
| 纯 β 反事实（投出 × 基准） | +3.88% | +1.17% |
| **空仓拖累（1−投出）× 基准** | **+0.91pp** | +1.11pp |
| 选品 α ≈ 一年收益 − 投出 × 基准 | +12.15% | +2.85%（为正 59.7%） |

- **"闲置现金零收益"的真实代价只有 0.91pp/年**（平均投出 53.7% × 基准均值）。
  这也就是"任何提高投出/给现金找收益的动作"的**天花板**。
- 策略并不是没有 α：中位超额 +8.37pp、胜率 65.4%。中位收益（4.40%）之所以低于基准中位（5.08%），
  是因为**两个分布的形状不同**（本账户右尾更肥、左尾也更深），不是因为策略在"输给基准"。
- 中位落点附近的两个 vintage 是**选品负 α**：2023 −6.92%、2024 −10.69%（2022 还是 +7.48%）。
  即"中位那段"的病根一半在**信号饥荒年份的选品质量**，不在 β。

> 修订：上一轮把 β 这条线的天花板说高了。真实天花板 ≈ **0.9pp/年**。

## 二、投出到底卡在哪（先把病灶摆清楚）

全窗口（2018-01-02 起同一条曲线）逐年：平均持仓 **14.3 / 32** 个槽位，投出 50.9%。

| 年 | 平均持仓 | 平均投出 | | 当日结论数 | 交易日数 | 当日平均投出 |
|---|---|---|---|---|---|---|
| 2019 | 9.11 笔 | 35.9% | | 0 笔 | 1337 | 35.8% |
| 2020 | 24.26 笔 | 88.8% | | 1 笔 | 333 | 64.4% |
| 2021 | 21.33 笔 | 80.1% | | 2 笔 | 164 | 73.6% |
| 2022 | 11.53 笔 | 43.1% | | 3+ 笔 | 279 | 93.7% |
| 2023 | 15.76 笔 | 51.4% | | | | |
| 2024 | **2.75 笔** | **9.5%** | | 有结论的交易日占比 | | **36.7%** |
| 2025 | 17.78 笔 | 66.3% | | | | |
| 2026 | 30.25 笔 | 94.7% | | | | |

**结构结论**：账户是"事件驱动"的 —— 只有当天出了结论才可能建仓，结论稀少时钱只能躺着。
63.3% 的交易日零结论，零结论日的平均投出 35.8%。要提投出，物理上只有两条路：
**让每笔活得久一点**（P1/P4/P5），或**让同一天的结论多进几笔**（P2）。

投出确实被拉起来了（50.9% → 63~69%），中位也从 4.40% 抬到 6~7%，
但**年化塌掉 4~9pp、Calmar 全线腰斩、跑赢基准从 65.4% 掉到 50~57%**。
（100/125 比 160/200 还差是非单调的：持有期跳档与槽位释放节奏耦合，说明这个旋钮本身不光滑。）

**P1′ 再加破位退出（连续 2 日收于 MA20 下 → 次日开盘平仓）→ 灾难**

| 变体 | 年化 | 回撤 | Calmar | 平均投出 | 平均持仓 | 成交 | 一年中位 | 跑赢基准 |
|---|---|---|---|---|---|---|---|---|
| 80/100 + 破位 | −0.89% | −17.59% | −0.051 | **10.2%** | **2.3** | **998** | −1.92% | 45.2% |

在**有限资金池**口径下，破位退出把仓位反复洗掉（998 笔卖出），而卖出后**没有资金回流渠道**
（重新建仓要等新结论、且每日 ≤2 笔），于是投出直接塌到 10.2%。
这正是 `config.py` 里那句注释的账户层证据：*"不降低总暴露、只把仓位在下跌中反复洗牌"*。

## 五、P3｜闲置现金计息 —— **唯一"严格占优"的一行**

把 `RISK_CONTROL["cash_yield"]` 从 0% 抬到无风险利率（**不新增任何标的**，只是闲置资金的收益率假设）：

| cash_yield | 年化 | 回撤 | Sharpe | Calmar | 平均投出 | 一年中位 | 为正 | 跑赢基准 |
|---|---|---|---|---|---|---|---|---|
| 0%（现行） | 16.66% | −33.13% | 0.829 | 0.503 | 50.9% | 4.40% | 58.5% | 65.4% |
| 1.0% | 17.24% | −32.35% | 0.852 | 0.533 | 50.9% | 4.91% | 60.2% | 66.6% |
| 1.5% | 17.52% | −31.96% | 0.864 | 0.548 | 50.9% | 5.17% | 60.9% | 67.0% |
| 2.0% | 17.81% | −31.57% | 0.875 | 0.564 | 50.9% | 5.43% | 61.2% | 67.2% |
| 2.5% | 18.10% | −31.17% | 0.887 | 0.581 | 50.9% | 5.69% | 61.9% | 67.6% |

三点读法：

1. **全表唯一"五项全改善"**：年化 ↑、回撤 ↓（更浅）、Calmar ↑、一年中位 ↑、为正率 ↑。
   单调、无尖峰、无参数敏感区。因为它不是"多冒险"，而是**把一笔本来收益为 0 的资产换成收益 >0 的资产**。
2. **它不稀释"跑赢基准"**：65.4% → 67.2%（**上升**）。这与上一轮的方向 C 正好相反 ——
   停泊基准 ETF 会把一部分钱变成基准（62.6%，下降），现金计息不会。
   这是"混入其他标的"与"现金管理"在口径上的分水岭。
3. **量级与天花板吻合**：中位 +1.03pp（2% 档），而第一节算出的空仓拖累上限是 0.91pp/年。
   两者对得上，说明这一项**已经把 β 这条线的天花板基本吃满了**。

⚠️ **必须披露的两件事**：

- 这不是新发现，是**把你自己在 2026-09-23 主动关掉的旋钮重新打开**
  （`config.py` 原注释："不再假设闲置资金有收益（保守口径，也免得把货基/保证金理财当成默认行为）"）。
  所以这是一个**产品口径决策**，不是技术发现。要落参就等于推翻 9-23 的决定。
- **2% 是满打满算的假设**。2019-2026 货基 7 日年化的区间大约 1.3%~2.6%，全程均值约 1.8%，
  且 2024-2026 明显偏低。**建议按 1.5% 报**（中位 5.17%、Calmar 0.548），或按逐年真实利率做动态序列。

## 六、P4 / P5｜"更聪明"的续持 —— 仍然是"用年化换中位"

P4 的设计比 P1 精细：**到期日之后若一个结论都没有，才继续持有到下一个结论日**（封顶 N 日）。
密集期一笔都不改，延长只作用在"本来会空闲的槽位"上。

| 40 日 | 14.17% | −33.99% | 0.417 | 58.0% | 16.2 | 5.80% | 60.4% | **64.3%** |

| 延展天数 | 年化 | 回撤 | Calmar | 平均投出 | 一年中位 | 为正 | 跑赢基准 |
|---|---|---|---|---|---|---|---|
| 基线 | 16.66% | −33.13% | 0.503 | 50.9% | 4.40% | 58.5% | 65.4% |
| 20 日 | 13.50% | −33.83% | 0.399 | 53.6% | 6.23% | 61.5% | 61.8% |
| 40 日 | 12.31% | −35.57% | 0.346 | 56.3% | 6.99% | 61.7% | 61.3% |
| 60 日 | 12.00% | −34.53% | 0.347 | 57.2% | 6.79% | 62.3% | 62.8% |
| 100 日 | 11.65% | −34.18% | 0.341 | 57.2% | **7.50%** | 63.3% | 60.4% |

**P4 的封顶 40 日是这一族里唯一"跑赢基准"没怎么掉的档（64.3%）**，但年化仍然 −2.5pp、Calmar 0.417。
它买到的中位（+1.40pp）比 P3 贵得多（P3 用 +1.03pp 中位换来了年化 +1.15pp）。

**机制解释（本轮最重要的一条）**：信号自带有效期 —— 80/100 日档的平均超额是 **+11.16% / +9.88%**
（`docs/周期错配归因审计-2026-09-24.md` 第三节），过了这个窗口，边际头寸的超额迅速转负。
所以"提高投出"买到的 β，标价是**持仓期限外的负 α**，它比 1pp 的现金拖累贵一个数量级。
这就是 A/B/C 三轮实验反复撞到同一堵墙的原因。

## 七、建议

1. **值得拍板的只有一条**：把闲置现金的收益率假设从 0% 恢复（建议 1.5%，可写 1.5~2%），
   即 `cash_yield`。它不引入任何标的、不加风险、不稀释超额，是全表唯一严格占优的一行；
   代价是推翻 9-23 的保守口径决定。**需要你明确点头，本轮未落参。**
2. **不建议动**：延长持有（P1/P4/P5）、到期延展（P5）、破位退出（P1′）。
   前三个都是"用 3~8pp 年化换 1.5~3pp 中位"；破位退出在有限资金池下直接是灾难。
3. **P2 可做可不做**：每日吞吐 2→4 几乎免费但 +0.45pp 中位、Calmar −0.005、跑赢 −1.5pp，
   不值得单独立一条口径变更。要动就顺手带。
4. **战略层面的转向**：中位的病根（第一节）一半在 2023/2024 vintage 的**选品负 α**（−6.9% / −10.7%）
   与信号饥荒，那属于 `docs/年度收益归因-2022-2026.md` 那条线，不在 β 这条线上。
   继续在"参与度"上找免费午餐，收益已封顶（0.9pp）且已吃掉。
5. **产品口径建议（非参数）**：现设计下"随机入场持有一年"的中位**结构性**只能落在基准中位附近 ——
   但同一份数据里**超额中位是 +8.37pp、胜率 65.4%**。复盘页只放中位，等于只展示了分布最不利的那个切点。
   建议在前端同时给出「超额中位 / 跑赢比例 / p5」，口径不变、代码不改、只改展示。
